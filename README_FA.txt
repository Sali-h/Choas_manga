راهنمای سریع
1) Node.js را نصب کن.
2) داخل همین پوشه دستور npm install را بزن.
3) برای امنیت، قبل از اجرا متغیر ADMIN_PASSWORD را تنظیم کن.
   ویندوز PowerShell: $env:ADMIN_PASSWORD="رمز-خودت"
4) npm start
5) مرورگر: http://localhost:3000
6) از /admin.html وارد مدیریت شو، رمز را بزن و صفحات هر چپتر را آپلود کن.

نکته: این نسخه برای اجرا روی کامپیوتر/سرور آماده است. برای اینکه دیگران در اینترنت ببینند،
باید آن را روی یک سرویس Node.js میزبانی کنی و ADMIN_PASSWORD را روی سرور تنظیم کنی.
